# AI Study Assistant

使用 Python 开发的命令行学习任务管理工具。
当前版本已完成基础任务管理，尚未接入 AI。

## 功能
- 添加和查看学习任务
- 标记任务完成
- 删除任务
- 统计总数、完成数、待完成数和完成率
- 使用 JSON 保存任务，重启后保留记录
- 拦截空任务、非整数编号和超出范围的编号

## 运行
需要 Python 3，无需安装第三方依赖。
在项目目录执行：

python main.py

根据菜单输入数字进行操作。

## 文件说明
- main.py：程序入口和任务管理逻辑
- tasks.json：自动生成的本地任务数据，不提交到 Git
- .gitignore：Git 忽略规则

## 已验证
- 添加任务、标记完成
- 非整数编号输入后继续运行
- 删除不存在的编号时提示错误
- 删除后统计结果正确
- 重启后保留完成状态和删除结果
